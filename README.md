# DDS 综合信号发生系统（DDS Comprehensive Signal Generator）

> 基于 **Cyclone IV FPGA + MSPM0G3519 MCU** 的直接数字频率合成（DDS）项目，支持正弦波、AM、FM 交互控制与显示。  
> A **Cyclone IV FPGA + MSPM0G3519 MCU** based DDS project supporting interactive Sine/AM/FM control and display.

---

## 1. 项目概览 | Project Overview

### 中文
- 本仓库包含两个核心工程：
  - `DDS_FPGA/`：Quartus FPGA 工程（波形生成、调制、数码管显示、UART 解析）。
  - `DDS_MCU/`：Keil MSPM0 工程（键盘输入、OLED UI、参数发送、外设驱动）。
- 系统通过 MCU 键盘/OLED 完成人机交互，再通过 UART 将模式与参数发送给 FPGA，由 FPGA 实时合成并输出 DAC 数字波形。

### English
- This repository contains two main projects:
  - `DDS_FPGA/`: Quartus FPGA design (wave generation, modulation, seven-segment display, UART parsing).
  - `DDS_MCU/`: Keil MSPM0 firmware (keypad input, OLED UI, parameter transmission, peripheral drivers).
- The MCU handles user interaction and sends mode/parameters over UART to the FPGA, which synthesizes real-time DAC waveform data.

## 3. 系统原理 | Core Principles

### 3.1 DDS 基本原理 | DDS Fundamentals

### 中文
- FPGA 内部使用相位累加器 + 正弦 ROM（`sine_14bit_256`）实现 DDS。
- 目标频率 `freq_target` 通过比例换算得到频率控制字 `freq_ctrl_word`：
  - 当前实现：`freq_ctrl_word = freq_target * 86`（对应 50 MHz 时钟下的近似系数）。
- 相位高位作为 ROM 地址，输出 14 位波形数据送 DAC。

### English
- The FPGA uses a phase accumulator plus sine ROM (`sine_14bit_256`) for DDS generation.
- Target frequency `freq_target` is converted into `freq_ctrl_word`:
  - Current implementation: `freq_ctrl_word = freq_target * 86` (approximation for a 50 MHz clock).
- Upper phase bits index the ROM; the 14-bit sample is sent to the DAC interface.

### 3.2 调制原理 | Modulation Principles

### 中文
- **AM（模式 B）**：载波与包络相乘，包络由调制度 `ma` 与低频调制波生成，并进行限幅输出。
- **FM（模式 C）**：利用调制波对 `fm_fc` 做频偏扰动，动态更新 `phase_step`。
- 调制参考波由独立 `mod_phase` 产生（代码中按 1 kHz 设计）。

### English
- **AM (Mode B):** carrier multiplied by an envelope derived from modulation index `ma` and low-frequency modulating wave, then clamped.
- **FM (Mode C):** frequency deviation is applied to `fm_fc`, producing a time-varying `phase_step`.
- The modulation reference wave is generated by a separate `mod_phase` path (configured as 1 kHz in code).

### 3.3 通信协议 | MCU–FPGA UART Protocol

### 中文
- 串口波特率：115200。
- 模式字符：
  - `A` → 正弦（Sine）
  - `B` → AM
  - `C` → FM
  - `D` → 预留（界面显示 PSK/ASK，FPGA 当前未完整实现）
- 参数发送格式：ASCII 数字 + `\n`（换行作为提交）。
- FPGA 解析时维护参数序号 `data_idx`，用于 AM/FM 多参数顺序写入。

### English
- UART baud rate: 115200.
- Mode characters:
  - `A` → Sine
  - `B` → AM
  - `C` → FM
  - `D` → Reserved (UI says PSK/ASK; not fully implemented in FPGA logic)
- Parameter format: ASCII digits + `\n` (newline as commit).
- FPGA tracks `data_idx` to assign multi-parameter inputs for AM/FM in order.

## 4. 功能说明 | Features

### 中文
1. **正弦波输出（A）**
   - 支持 Hz/kHz/MHz 量级输入并换算后发送。
2. **AM 调制（B）**
   - 可设置载波频率 `Fc` 与调制度 `ma`。
3. **FM 调制（C）**
   - 可设置载波频率 `Fc` 与频偏 `Dev`（示例 5k/10k 切换）。
4. **显示与交互**
   - MCU：OLED 菜单、参数输入与状态反馈。
   - FPGA：6 位数码管显示频率信息与 AM 调制度。
5. **外设支持**
   - 4x4 键盘扫描、OLED SPI、W25Q64 SPI 驱动框架。

### English
1. **Sine output (A)**
   - Accepts Hz/kHz/MHz style input and transmits converted frequency.
2. **AM modulation (B)**
   - Configurable carrier frequency `Fc` and modulation index `ma`.
3. **FM modulation (C)**
   - Configurable carrier `Fc` and deviation `Dev` (e.g., 5k/10k toggle).
4. **Display & interaction**
   - MCU: OLED menu, parameter input, status feedback.
   - FPGA: 6-digit seven-segment display for frequency and AM index.
5. **Peripheral support**
   - 4x4 keypad scanning, OLED SPI driver, W25Q64 SPI framework.

## 6. 使用方法 | How to Use

### 6.1 FPGA 端 | FPGA Side

### 中文
1. 用 Quartus 打开 `DDS_FPGA/DDS_simple.qpf`。
2. 检查 `DDS_simple.qsf` 中引脚是否与硬件一致（时钟、UART、DAC、数码管、开关）。
3. 编译并下载到 FPGA。
4. 确认 DAC 时钟 PLL 已锁定（`locked` 信号）。

### English
1. Open `DDS_FPGA/DDS_simple.qpf` in Quartus.
2. Verify `DDS_simple.qsf` pin assignments match your board (clock, UART, DAC, display, switch).
3. Compile and program the FPGA.
4. Confirm DAC PLL lock (`locked` signal).

### 6.2 MCU 端 | MCU Side

### 中文
1. 用 Keil 打开 `DDS_MCU/Project/DDS.uvprojx`。
2. 确保 SysConfig 生成步骤可用（工程中配置了构建前调用 `syscfg.bat`）。
3. 编译并下载到 MSPM0G3519。
4. 上电后通过键盘进入模式 A/B/C，输入参数并发送。

### English
1. Open `DDS_MCU/Project/DDS.uvprojx` in Keil.
2. Ensure SysConfig pre-build generation works (`syscfg.bat` is configured in project settings).
3. Build and flash the MSPM0G3519 firmware.
4. After boot, use keypad to select A/B/C modes, input parameters, and transmit.

### 6.3 联调流程 | End-to-End Bring-Up

### 中文
1. 先下载 FPGA，再下载 MCU。
2. 确认 MCU UART TX 与 FPGA `uart_rx` 连线正确且共地。
3. 在 MCU 上选择模式并发送参数，观察：
   - FPGA DAC 输出波形
   - FPGA 数码管显示
   - MCU OLED 反馈

### English
1. Program FPGA first, then MCU.
2. Verify MCU UART TX ↔ FPGA `uart_rx` wiring and common ground.
3. Select mode and send parameters from MCU; observe:
   - FPGA DAC waveform output
   - FPGA seven-segment display
   - MCU OLED feedback

## 8. 后续优化建议 | Future Recommendations

### 中文
1. **完成模式 D 实装**：补齐 PSK/ASK 发射链路与参数协议。  
2. **协议增强**：加入帧头、长度、校验（CRC）与 ACK，提高抗干扰能力。  
3. **参数边界保护**：在 MCU 与 FPGA 双侧统一做频率、调制度、频偏范围限制。  
4. **数值精度优化**：将 `freq_target * 86` 升级为更高精度定点换算。  
5. **工程清理**：分离生成文件、备份文件与源文件，减少仓库噪音。  
6. **自动化验证**：增加仿真 testbench（UART 输入序列、AM/FM 频谱与幅度检查）。  
7. **文档与硬件图**：补充接线图、串口指令手册、模式时序图。  

### English
1. **Implement Mode D fully** (PSK/ASK signal chain + protocol).  
2. **Strengthen UART protocol** with frame header, length, CRC, and ACK.  
3. **Add consistent parameter limits** on both MCU and FPGA sides.  
4. **Improve frequency-word precision** beyond the current `* 86` approximation.  
5. **Clean repository artifacts** (generated outputs/backups vs source files).  
6. **Add automated verification** (testbench for UART sequences and AM/FM checks).  
7. **Expand documentation** with wiring diagrams, command reference, and timing charts.
